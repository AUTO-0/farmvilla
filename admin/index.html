Local workspace · no cloud sync
Local workspace — not a secure live booking backend. Records stay only in this browser/device; clearing browser data can erase them. There is no staff login, shared availability, online payment or automated guest notification. Avoid entering sensitive guest data in a shared device. Export backups regularly. Never use this as the sole record of confirmed paid bookings.
